# Architecture Decision Records

One file per decision, numbered, never deleted. A superseded decision gets
`Status: superseded by ADR-XXXX` — history stays intact.

Template:

```markdown
# ADR-XXXX: Title

- Status: accepted | superseded by ADR-YYYY
- Date: YYYY-MM-DD

## Context
## Decision
## Consequences
```
